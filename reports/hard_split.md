## What it means

On these harder tasks the multi-agent system was right where CoT-SC was wrong 1 time(s) and wrong where CoT-SC was right 3 time(s) (p = 0.625). The concise-answer step changed Always-MAS from 91.7% to 97.9% (p = 0.25). An oracle gate would reach 97.9% by escalating 2.1% of tasks; the learned gate reached 95.8% escalating 2.1%.

48 tasks and one run are small: differences of a few tasks are within noise, and these tasks were written and checked by the assistant, so they need the same human review as the main split before being cited.
