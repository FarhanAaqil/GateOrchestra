# Archived simulation reports

These were produced in `mock` mode, before any real-LLM run. The simulator
built probe samples from the ground truth and modelled Always-MAS as always
correct, so none of these numbers are evidence about GateOrchestra.

They are kept only as a record of development. The real results are in
`results/real/final/`, analysed in `reports/final_analysis.md` and written up
in `reports/research_report.md`.
